# Papercal

A paper-calendar log for supplements, meds, stimulants, activity, and metrics.

Data lives in this browser on this device (`localStorage`). There is no account and no wearable sync.

## Categories

- **Supplements** (light green)
- **Meds** (light blue)
- **Stimulants** (light red)
- **Activity** (light orange) — total 1–10 plus multi-select tags
- **Metrics** (grey) — sleep hours, wakefulness, vigor

Filter chips at the top of the Day view. Morning / Evening **Check all** works across categories.

## Daily use

- Tap a checklist item once to mark taken, again for “not today,” a third time to put it back as planned.
- ⋯ menu: clear this day, stop future days, change dose for this day (unit stays fixed).
- Activity: tap the tags you did. Edit the tag list anytime.
- Blank cells are not zeros in the export. Only an explicit skip or a typed number becomes data.

## Schedules

Every day, specific weekdays, or every N days (including every other day).

## Devices

iPhone and iPad do not share a log automatically. Use one device as home base. Export JSON → AirDrop → Merge from JSON. Export CSV or JSON to Windows for analysis. Category is included in the CSV column headers.

## Find last time

Data screen → type a name → recent dates with a jump button.

Safari can evict site data for pages you only open in a tab. Add to Home Screen and use that icon.
